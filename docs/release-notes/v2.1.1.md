## HGhub 合并版 2.1.1（简化版，Muse 2026-11-15）

以合并版 2.1.0 为底，按用户定版做减法：操作只留简单入口，修游客偏好回滚。

### 修复

- 合入上游 #113：游客模式保存观看进度、收藏时不再回滚静音、音量、画质、滑动切集、搜索历史等偏好（accountData 白名单隔离）。
- 合入上游 #111：评论区 HTML/脚本片段清理、长文本布局、评论计数显示。

### 删除（简化）

- 分区长按（左下减速 / 右上加速 / 中心标签菜单）与首次手势提示图：长按改为任意位置临时倍速 2x、松手恢复，提示只用底部小 pill。
- 启动静音整体移除（含设置开关）：启动恒有声；一次性迁移清掉旧版已持久化的启动静音偏好，只动这一项。
- 开屏动画与首次使用协议强制门：App 直进（协议文本仍可在设置里查看）。
- 设置里的「检查更新」入口（合并版版本由自建编译交付）。
- 「我的」页登录卡片与登录/退出入口：打开直接是本地收藏与观看历史。
- Feed 分享按钮、播放锁定按钮与锁定浮层。
- 标签屏蔽的设置页外入口（Feed/详情/吃瓜的「不感兴趣」与标签菜单、详情标签跳转）：标签纯文本展示，规则只在设置页管理。

### 新增

- 全屏横屏：横屏视频进全屏自动横屏（原生方向请求 + CSS 旋转兜底）；全屏底栏与独立播放器均加横竖屏切换按钮。
- 独立播放器双击切播放/暂停（单击/双击延时判定，不再连切两次）。

## HGhub 合并版 2.1.2（修复+全检，Muse 2026-11-15）

以合并版 2.1.1 为底，按用户真机验收反馈修正三件事：开场静音的正确规格、全屏方向跟源走、切集直达。

### 修复

- **开场静音（2.1.1 理解反了，本版纠正）**：每次打开 App 恒静音开场（防外放尴尬）；会话内手动取消静音后本次会话保持有声，保存进度/收藏不再改回静音（#113 隔离保留）。不恢复设置开关，恒定行为；2.1.1 的首启强制取消静音迁移已删除。
- **全屏方向跟源走**：横屏源点全屏直接横屏、竖屏源直接竖屏，判定只认 video 元素真实宽高（进全屏直读播种 + loadedmetadata/resize 复判 + 全屏期间换源复判，原生请求统一由判定驱动）。旋转按钮与 override 状态机整套删除（2.1.1 的 toggle 只按 CSS 层翻转、原生横屏后永远回不到竖屏，是死结）。退出全屏回竖屏。
- **全屏底栏溢出**：总时长不再被裁——当前/总时长合并为一段文本，分段布局（左：播放/时间/声音；右：超分/倍速/上集/下集/选集），全元素同现约 372px 不溢出。
- **横屏手势轴向**：CSS 旋转兜底时手势按视觉坐标解释（视觉上滑=下一集、下滑=上一集、横拖 seek 不变），沿用既有主导方向判定框架。
- 独立 Player 退出全屏补发竖屏复位请求；Player 控制栏删第二份重复时间文本。

### 简化（删中间层）

- **选集直达（两处落点，同一网格）**：①全屏底栏「选集」钮；②首页左下「详情 · 第X集」拆成两个独立点击目标——「详情」开详情面板、「第X集」直达选集网格。都是 2 步（钮→集数），不再穿详情页签。详情面板本体（简介/标签/相关推荐）完整保留。
- **右侧栏「切集」开关钮删除**：连带移动端对 swipeEp 开关的读取一并清除——竖滑切集恒定生效（多集先切集、到头切剧），不存在「先点钮进模式再滑」的中间状态。选集走直达钮，不靠模式。
- **上集/下集钮**：底栏成对出现（多集时），与滑动切集并行。
- **全屏藏闲杂**：进全屏后右侧竖排操作栏、右上浮层（超分 pill/声音/搜索）整层隐藏，画面只留底栏控制条（声音钮已移入底栏）；退出全屏整层恢复。
- **超分双份重复消除**：全屏时超分只留底栏一处。
- 详情面板内隐藏「+关注」钮（游客点它必弹登录框；关注入口保留在作者主页）。
- 设置里已无入口的检查更新死代码（checkUpdate/新版本弹窗）整套删除。

### 全屏纯净 + 选集分位 + 画质

- **全屏 = 纯净模式**：进全屏默认全隐（控制层/侧栏/浮层/标题全隐），只看视频；单击呼出控制层、再单击收起（沿用单击翻转）。呼出的只有有用控制：播放/进度/上下集/选集/画质/倍速/超分/声音/退出全屏；评论、点赞、收藏一律不进全屏（右侧栏本就被全屏整层关断，本版核对确认）。
- **选集钮按方向分位**：横屏全屏在底栏（与上下集/倍速/超分并列）；竖屏全屏在右侧中段（原「切集」钮的位置），同属单击呼出层。
- **画质默认最高档**：有 HEVC 高清流时默认就用它（旧默认是省流向的标准档）——一次性迁移，老用户首次升级自动切高清，之后手动关掉不再被改回；全屏底栏新增画质切换钮（HD/标清）。源分辨率上限由平台决定，客户端只能选档不能升源。
